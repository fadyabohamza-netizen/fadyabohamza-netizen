# Hi there, I'm Fady Abohamza 👋

I build **AI agents**, **developer tools** and **automation pipelines** on the [Pollinations](https://pollinations.ai) platform — turning plain language into working software. I enjoy getting my hands into every layer: prompt agents that ship as single `agent.json` files, live web apps that call the Pollinations API, and media pipelines that generate images, audio and video at scale.
